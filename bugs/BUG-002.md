1. Zusammenfassung (2–3 Sätze)

Silent or incomplete exception handling during template fetches can lead to misleading errors or silent failures. Network timeouts and other generic errors during the fetch should be explicitly caught and handled, raising a clear HTTPException with a timeout or network error message.

2. Betroffene Stellen
Datei | Zeile(n) | Rolle

3. Code-Snippet (eingebettet)

```python
// backend/api/db/crud/templates.py:215-224
    try:
        opener = urllib.request.build_opener(SafeRedirectHandler())
        with opener.open(template.url, timeout=TEMPLATE_FETCH_TIMEOUT_S) as fp:
            if ext.rstrip() in (".yml", ".yaml"):
                loaded_file = yaml.load(fp, Loader=yaml.SafeLoader)
            elif ext.rstrip() in (".json"):
                loaded_file = json.load(fp)
            else:
                print("Invalid filetype")
                raise HTTPException(status_code=422, detail="Invalid filetype")
```

4. Erwartetes Verhalten

Network timeouts and other generic errors during the fetch should be explicitly caught and handled, raising a clear HTTPException with a timeout or network error message.

5. Tatsächliches Verhalten

If the fetch times out, it throws an `urllib.error.URLError` (or `socket.timeout`) which is caught by a broad `except Exception as exc:` block that might obscure the actual timeout issue or fail to report it clearly to the user.

6. Reproduktion

1. Add a template with a URL that times out (e.g., a blackholed IP).
2. Refresh the template.
3. Observe the error response.

7. Root-Cause-Analyse

Broad exception catching masks specific fetch errors (like timeouts) making debugging difficult for users.

8. Impact

- User-Impact: Admins trying to add/refresh templates.
- Daten-Impact: None.
- Security-Impact: None.

9. Fix-Richtung (kein Code, nur Strategie)

Explicitly catch `urllib.error.URLError` and `socket.timeout` before the generic `Exception` catch block and raise a descriptive 400/504 HTTPException.

10. Test-Vorschlag

Test fetching from a URL that times out and ensure the error message clearly states it was a timeout.
