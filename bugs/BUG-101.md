1. Zusammenfassung
In `deploy_app` wird das von User gesendete DeployForm nahezu ungefiltert weiterverarbeitet und im Verlauf potentiell als `env_file` oder env mapping an Docker-Compose geschrieben. Fehlende Validierung kann zu Injection führen.

2. Betroffene Stellen
Datei: backend/api/actions/apps.py
Zeile: 281
Rolle: deploy_app Function

3. Code-Snippet
```python
async def deploy_app(template: DeployForm):
    # payload parsing without explicit sanitization of environment keys
```

4. Erwartetes Verhalten
Keys und Values im Environment-Dictionary sollten validiert werden, um Injection von Compose-Variablen wie `${PWD}` oder Path-Traversal zu verhindern.

5. Tatsächliches Verhalten
Ungefilterte Weitergabe.

6. Reproduktion
Sende ein DeployForm mit manipulierten ENV-Keys.

7. Root-Cause-Analyse
Fehlende Sanitization im API Endpoint vor Weitergabe an das Backend-System.

8. Impact
Security: Medium (im Kontext eines Admins).

9. Fix-Richtung
`validators` auf dem `DeployForm` hinzufügen, die ENV-Keys auf `^[a-zA-Z0-9_]+$` beschränken.

10. Test-Vorschlag
Mock-Request mit invalidem ENV-Key senden und 422 erwarten.
