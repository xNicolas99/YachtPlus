1. Zusammenfassung
Bandit (B104) warnt vor `Possible binding to all interfaces.` in `backend/api/utils/security.py`, Zeile 16. Wenn in FastAPI Anwendungen Socket-Interfaces hartcodiert auf `0.0.0.0` gebunden werden, kann das je nach Deployment Security-Implikationen haben.

2. Betroffene Stellen
Datei: backend/api/utils/security.py
Zeile: 16
Rolle: IP/Network Util

3. Code-Snippet
Statische Analyse (Bandit Output B104).

4. Erwartetes Verhalten
Bindings sollten via ENV konfigurierbar sein (z.B. `127.0.0.1` als Default).

5. Tatsächliches Verhalten
Harcode `0.0.0.0`.

6. Reproduktion
`bandit -r api/` zeigt die Warnung.

7. Root-Cause-Analyse
Hardcoded Listen-Address.

8. Impact
Security: Low (Im Container-Umfeld meistens gewollt, aber Bandit schlägt an).

9. Fix-Richtung
Wenn gewollt, Bandit-Ignorer `# nosec B104` hinzufügen, andernfalls per Config injecten.

10. Test-Vorschlag
Bandit Output prüfen.
